#+title: Proxy Configuration

An Ansible repository for managing proxy clients, a Docker Compose proxy server,
Proxmox/OpenWrt workloads, and portable sing-box profiles.

* Current topology

The inventory currently contains one Docker VPS:

| Host | Group | Managed services |
|---+---+---|
| =bwg-cn2-gia= | =vps_group= | Caddy, Xray, WARP, Magpie (monitoring/RSS/asspp disabled) |
| =mcp-fetch= | =mcp_group= | MCP fetch server |
| =localhost= | =local_group= | Native sing-box client |
| =pve= | =pve_group= | Proxmox/OpenWrt workload management |

The VPS service list is defined in =host_vars/bwg-cn2-gia.yml=. See
[[file:docs/services.org][docs/services.org]] for the service table, dependencies, and placement rules.

* Quick start

#+begin_src sh :results output silent
  make deps
  make syntax
  make test
  make check
  make diff
#+end_src

Do not run an apply target until the check/diff output has been reviewed. Runtime
secrets are read from =pass=; their paths are stored in inventory variables, not
in the repository.

* Common commands

| Command | Purpose |
|---+---|
| =make local= | Apply workstation changes, skipping binary installs |
| =make local-install= | Apply workstation changes including binary installs |
| =make server= | Deploy the VPS play |
| =make pull= | Pull selected VPS images without stopping services |
| =make cleanup= | Explicitly clean unused VPS images and APT downloads; preserve data |
| =make pve= | Apply Proxmox workload management |
| =make openwrt= | Apply the OpenWrt client play |
| =make check= | Run the complete playbook in check mode |
| =make diff= | Run check mode with diffs |
| =make test= | Run service/template tests and sing-box profile validation |
| =make ci= | Run syntax checks and the complete test suite |

Use =LIMIT=, =TAGS=, =SKIP_TAGS=, and =EXTRA= to refine a command. VPS commands
use the dedicated =server.yml= playbook, so native Ansible limit patterns cannot
select local or Proxmox plays:

#+begin_src sh :results output silent
  make server LIMIT=bwg-cn2-gia
  make pull LIMIT=bwg-cn2-gia
  make diff LIMIT=localhost TAGS=gateway
#+end_src
