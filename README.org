*** API and Dashboard
The native sing-box gRPC/gRPC-Web API and dashboard listen on loopback only.
Open [[http://127.0.0.1:9090/dashboard/]] and connect to =127.0.0.1:9090=
without a secret. The listener is intentionally unavailable from LAN and
Tailscale; change the listen address and configure =services[].secret= before
enabling remote access.

*** iCloud profile
Exports a portable profile to the sing-box Apple client iCloud containers,
landing at =iCloud Drive/sing-box/sing-box.json=. In the app, add a profile of
type =iCloud= and set =Path= to =sing-box.json=.

Dropped from this profile: the host-local log path, the loopback API/dashboard,
and the site-local outbounds gated on =host_env=. Everything else, Tailscale
included, matches the workstation config, so the file carries the Tailscale
auth key and is written =0600=.
#+begin_src sh :results output silent
  make local TAGS=icloud
#+end_src

*** Windows profile
Exports a portable profile for the official Windows sing-box client
(=winget install sing-box=), landing at
=~/.config/sing-box/windows/sing-box.json=. Copy that file to the Windows
machine. TUN needs an elevated process and the =wintun= DLL that ships with
the winget/scoop package. From an elevated prompt:

#+begin_example
  sing-box.exe run -c sing-box.json --directory %LOCALAPPDATA%\sing-box
#+end_example

Dropped from this profile: the host-local log path and the site-local
outbounds gated on =host_env=. The loopback API/dashboard stays, unlike the
iCloud export. Tailscale is kept, so the file carries the Tailscale auth key
and is written =0600=. Process rules include the Windows =.exe= names.
#+begin_src sh :results output silent
  make local TAGS=windows
#+end_src

** Ansible

Common workflows are wrapped in the =Makefile=. Run =make= (or =make help=) to
list every target. =check= and =diff= accept =LIMIT=, =TAGS=, =SKIP_TAGS=, and
=EXTRA=. Role deployment targets accept =TAGS=, =SKIP_TAGS=, and =EXTRA= where
applicable. =PLAYBOOK= can override the playbook path globally.

#+begin_src sh :results output silent
  make deps                       # install Galaxy requirements
  make syntax                     # fast parse validation
  make test                       # render and check sing-box profiles
  make ci                         # syntax + sing-box profile checks
  make check                      # dry-run against the inventory
  make diff                       # dry-run with a diff of changes
  make local                      # apply to localhost, skip binary installs
  make local-install              # apply to localhost, incl. binary installs
  make server                     # deploy to the vps_group
  make pve                        # apply the roles in the Proxmox play
  make openwrt                    # apply the roles in the OpenWrt play
  make pull                       # pull Docker Compose images on the server
  make lint                       # ansible-lint (if installed)

  make check LIMIT=bwg-cn2-gia    # override: limit to one host
  make server TAGS=pull           # override: run only tagged tasks
  make local TAGS=icloud          # override: re-export the iCloud profile only
  make local TAGS=windows         # override: re-export the Windows profile only
  make diff EXTRA="--ask-vault-pass"
#+end_src

*** OpenWrt

The =openwrt= base role bootstraps Python, gathers facts, preserves the
image-provided feed list, and replaces only the official download host with
=openwrt_package_mirror=. OpenWrt 25.12 or newer with =apk= is required.
Snapshot builds retain the official source by default to avoid mirror
synchronization gaps. Client roles such as =xray_client= and =sing-box_client=
can run after this base role. Run the VM and guest stages separately so the
guest has time to boot and become reachable:

#+begin_src sh :results output silent :async
  make pve
  make openwrt
#+end_src
